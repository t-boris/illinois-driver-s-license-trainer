## Question

Откуда берётся учебный контент (вопросы, правила, объяснения)?

## Why it matters

От этого зависит структура данных, точность подготовки и юридическая/этическая корректность. Экзаменационные вопросы Иллинойса официально не публикуются — их нужно либо составить по официальному руководству, либо сгенерировать и проверить.

## Options

- **A**: Составить вопросы вручную/с помощью ИИ строго по официальному Illinois Rules of the Road, с ручной проверкой.
- **B**: Сгенерировать банк вопросов ИИ по темам без систематической сверки с руководством.
- **C**: Использовать существующий открытый/лицензируемый банк вопросов и перевести его.

## Recommended

A — Цель — «максимально подготовить к экзамену», значит точность важнее скорости; ИИ можно использовать для черновиков, но с обязательной сверкой по официальному руководству.

## Answer

A. Составить вопросы вручную/с помощью ИИ строго по официальному Illinois Rules of the Road, с ручной проверкой.

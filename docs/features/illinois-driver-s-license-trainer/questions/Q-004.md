## Question

Нужны ли пользователям аккаунты и сохранение прогресса между устройствами?

## Why it matters

Определяет, есть ли бэкенд/база данных, аутентификация и обработка персональных данных в первой версии.

## Options

- **A**: Без аккаунтов: прогресс хранится только в браузере устройства.
- **B**: Необязательный вход (например, через Google) для синхронизации прогресса; без входа — всё тоже работает.
- **C**: Обязательная регистрация.

## Recommended

A — Для v1 убирает бэкенд и риски с данными; B — естественный следующий шаг.

## Answer

A. Без аккаунтов: прогресс хранится только в браузере устройства.

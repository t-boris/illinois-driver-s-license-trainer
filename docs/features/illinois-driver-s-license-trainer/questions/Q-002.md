## Question

Как выглядит основной путь обучения пользователя?

## Why it matters

Это ядро продукта: определяет экраны, модель прогресса и то, что считать готовностью к экзамену.

## Options

- **A**: Только тесты: практика по темам + симуляция экзамена, без уроков.
- **B**: Уроки по темам (с картинками) → квиз по теме → симуляция экзамена, с прогрессом по темам.
- **C**: Игровая прогрессия («дорога к правам»): уровни, очки, стрики, разблокировка тем, финальный «экзамен».

## Recommended

B — Даёт реальную подготовку и место для картинок/юмора; элементы геймификации из C можно добавить поверх позже.

## Answer

B. Уроки по темам (с картинками) → квиз по теме → симуляция экзамена, с прогрессом по темам.

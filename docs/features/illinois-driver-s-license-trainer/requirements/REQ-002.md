## Statement

The application must be fully usable on phones and on desktop browsers.

## Acceptance Criteria

- [ ] All screens are usable on a 360px-wide viewport without horizontal scrolling.
- [ ] Interactive elements on mobile are touch-friendly (min ~44px tap targets).
- [ ] Layout adapts to desktop widths without stretched or empty layouts.
- [ ] Works in current versions of Safari (iOS), Chrome (Android/desktop) and Firefox.

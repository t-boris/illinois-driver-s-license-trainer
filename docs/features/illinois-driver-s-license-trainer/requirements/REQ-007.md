## Statement

The application must track the user's results per topic and per exam simulation and show a readiness indicator: the user is 'ready' when every topic has reached the correct-answer threshold and at least one exam simulation has been passed. Progress is stored only in the browser of the current device; there are no accounts.

## Acceptance Criteria

- [ ] The home screen shows progress per topic, weak topics, and the overall readiness state.
- [ ] Readiness turns 'ready' only when all topics meet the threshold AND a simulation has been passed; otherwise it tells the user what remains.
- [ ] Progress survives page reload and browser restart on the same device.
- [ ] The user is informed that progress is device-local and can reset it explicitly.

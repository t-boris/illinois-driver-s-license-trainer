## Statement

The application must offer separate sections for studying and practising, not only tests and exams: Learn (lessons), Signs (sign gallery), Terms (glossary), Practice (topic quizzes) and Exam simulation (DEC-022).

## Acceptance Criteria

- [ ] The home screen shows separate entries for Learn, Signs, Terms, Practice and Exam simulation, each reachable in one tap, in both languages.
- [ ] Learn lists the topics and opens an illustrated lesson per topic.
- [ ] Signs shows a gallery grouped by category (regulatory, warning, guide, construction, signals, pavement markings); opening a sign shows its image, name and meaning in the active language; all images come from the official sign library.
- [ ] Terms shows a searchable bilingual glossary: each entry has the English exam term, its Russian equivalent and a short definition; in English UI the Russian equivalent is hidden or secondary.
- [ ] Terms and sign cards carry a manual section reference, manual version and RU/EN review records and are blocked by the build gate when any is missing.
- [ ] Practice lists the topic quizzes; Exam simulation is a separate entry.
- [ ] Signs and Terms do not change readiness (DEC-002).

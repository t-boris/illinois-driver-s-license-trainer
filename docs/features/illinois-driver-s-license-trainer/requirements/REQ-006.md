## Statement

The application must be deployable to and run on Vercel. The Vercel build must include the build-time content validation step defined in DEC-008: every learning content item (lessons, questions, answers, explanations) stored in the repository must carry its Rules of the Road section reference, the manual version/date it was verified against, and review records for Russian and for English (reviewer, date); if any item lacks the section reference or either review record, the build fails and nothing is deployed. This applies to production and preview deployments alike, so unreviewed content can never reach a public URL.

## Acceptance Criteria

- [ ] The production build deploys to Vercel from the repository without manual steps.
- [ ] A public URL serves the application over HTTPS.
- [ ] Preview deployments are produced for changes before release (standard Vercel behaviour).
- [ ] The Vercel build command runs the content validation script defined in DEC-008 before the application build completes.
- [ ] When any content item lacks the Rules of the Road section reference, the Vercel build fails and no deployment (production or preview) is published.
- [ ] When any content item lacks the Russian review record (reviewer, date) or the English review record (reviewer, date), the Vercel build fails and no deployment (production or preview) is published.
- [ ] When every content item carries the section reference, the manual version/date, and both review records, the validation step passes and the deployment proceeds.

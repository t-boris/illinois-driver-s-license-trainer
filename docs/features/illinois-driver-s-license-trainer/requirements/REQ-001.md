## Statement

The application must present all interface text and all learning content (lessons, questions, answers, explanations) in both Russian and English, with the user able to switch language at any time without losing progress. In addition, on every question screen (topic quiz and exam simulation) a user viewing Russian can reveal the original English wording of the question and its answer options next to the translation.

## Acceptance Criteria

- [ ] Every UI string and every content item exists in both RU and EN; no mixed-language fallbacks are visible to the user.
- [ ] The language switch is reachable from any screen and takes effect immediately without resetting the current quiz or stored progress.
- [ ] On each question screen in Russian, a 'Show in English' control reveals the English question text and answer options alongside the Russian ones; the control can be collapsed again.
- [ ] The revealed English block does not hide the question image or the answer controls on a phone-sized screen.
- [ ] When the UI language is English, the control is not shown (or is inert) since the content is already in English.

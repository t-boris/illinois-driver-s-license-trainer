## Statement

The application must prepare the user for the Illinois written knowledge test through a topic-based path: an illustrated lesson per topic → a quiz on that topic → a full exam simulation modelled on the real Illinois test (question count, mix of rules and signs, passing score verified against official sources). Topics together must cover the Illinois Rules of the Road and road signs.

## Acceptance Criteria

- [ ] Each topic has a lesson, a quiz with explanations for every answer, and a visible completion state.
- [ ] Exam simulation draws questions across all topics, uses the real test's question count and pass threshold (verified), and shows pass/fail with a per-topic breakdown.
- [ ] Every question is traceable to a section of the official Illinois Rules of the Road and has been manually reviewed in both languages.

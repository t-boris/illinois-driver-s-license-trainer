## Statement

The tone, copy and visual style must be fun and encouraging, never punitive, in both languages.

## Acceptance Criteria

- [ ] Feedback for wrong answers is encouraging and includes a learning hint.
- [ ] Progress and achievements are celebrated (e.g. streaks, badges or similar).
- [ ] Copy in both languages is reviewed for a consistent light, friendly voice.

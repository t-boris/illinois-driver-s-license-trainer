## Statement

The tone, copy and visual style must be fun and encouraging, never punitive, in both languages. Per DEC-003, the voice is written primarily for Russian-speaking adult immigrants in Illinois taking the written test for the first time or re-qualifying: humour and examples are adult-oriented, English remains fully supported with the same light, friendly voice, and Russian explanations bridge to the English terminology used on the real Illinois exam (the exact bridging mechanism is an open question and is not fixed by this requirement). Per the resolution of F-002 and consistent with DEC-002, celebration in v1 is limited to encouraging feedback at progress milestones (topic completion, reaching the readiness threshold, passing an exam simulation); a persistent achievement system (badges, streaks, trophies or similar) is out of v1 scope.

## Acceptance Criteria

- [ ] Feedback for wrong answers is encouraging and includes a learning hint.
- [ ] Completing a topic triggers an encouraging celebration message or animation in the active language.
- [ ] Reaching the readiness threshold triggers an encouraging celebration message or animation in the active language.
- [ ] Passing an exam simulation triggers an encouraging celebration message or animation in the active language.
- [ ] No persistent achievement system exists in v1: the app stores or displays no badges, streak counters, trophies or similar accumulating rewards.
- [ ] Copy in both languages is reviewed for a consistent light, friendly voice.
- [ ] Humour and examples in copy are adult-oriented and written for Russian-speaking adult immigrants in Illinois; no copy is targeted at or written for minors.
- [ ] English copy has full feature parity with Russian copy — no screen, hint or celebration message exists in one language without an equivalent in the other.
- [ ] Every Russian explanation that introduces a rule or sign concept also presents the corresponding English term as used on the real Illinois written test.
- [ ] No copy element shames, mocks or penalises the user for mistakes (e.g. no negative scoring language, no loss-of-progress threats) in either language.

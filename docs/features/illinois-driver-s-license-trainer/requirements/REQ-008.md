## Statement

The application must collect anonymous, aggregated usage analytics — topic/page views, per-question and per-topic correct/incorrect counts, exam-simulation pass/fail outcomes — without identifying the user and without cookies or persistent identifiers that would require a consent banner. A short privacy note in both languages must describe what is collected.

## Acceptance Criteria

- [ ] No analytics event contains personal data, a user account, or a stable cross-session identifier for the user.
- [ ] Per-question correct/incorrect counts and per-topic results are available in aggregate to the content maintainers.
- [ ] The app shows no cookie/consent banner; a privacy note (RU and EN) is reachable from the app and lists the collected data categories.
- [ ] If the analytics endpoint is unavailable, the learning experience is unaffected (events are dropped silently).

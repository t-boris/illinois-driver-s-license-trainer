## Context

DEC-006 requires anonymous aggregated analytics without cookies or persistent identifiers; the provider was left to the implementer.

## Alternatives

1. Vercel Web Analytics
2. Plausible or similar hosted analytics

## Decision

A Vercel serverless function /api/event receives anonymous events and increments aggregate counters per question, topic and simulation outcome in a Neon Postgres table. No IP address, user agent, cookie or identifier is stored. The client sends events only when VITE_ANALYTICS_URL is set and drops them silently on failure.

## Reason

Full control, no third party, no identifiers, supports per-question counts.

## Consequences

Requires a Neon project and DATABASE_URL in Vercel; creating it needs the owner's explicit go-ahead. The privacy note lists exactly the stored categories.

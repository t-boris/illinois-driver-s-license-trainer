## Context

The first UI was functional but plain, and lessons rendered as one dense block of text. The owner asked for a more attractive and modern look.

## Alternatives

1. Add a UI component library (rejected: DEC-011 stack and the no-new-libraries rule)
2. Load fonts from a font CDN (rejected: third-party requests conflict with the privacy promise in DEC-006)

## Decision

The interface adopts the visual language of American highway signs: guide-sign green panels with a white inset border, sign-shape pictograms (octagon, diamond, school pentagon, circle) for the home sections, warning yellow accents, a segmented readiness bar, and amber (never red) encouraging feedback for wrong answers. Type is Rubik, self-hosted as WOFF2 under public/fonts (SIL OFL, licence file included); no third-party requests. Lessons are rendered from a small markup (paragraphs, `## ` headings, `- ` bullets, `**bold**`) and the drafts were restructured into short sections without changing any fact. CSS only, no new libraries; light and dark themes, reduced motion respected, keyboard focus visible.

## Reason

Matches the product's subject, supports the playful but adult tone (REQ-004), and keeps the app fast and private.

## Consequences

Lesson bodies use the small markup; the review of lesson content should check headings and bullets as well as facts. Rubik's licence file ships with the app.

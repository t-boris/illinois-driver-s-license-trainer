## Context

DEC-005 and REQ-004 were justified by the assumption that the Illinois written test is English-only. External fact (to be verified against the official Illinois SOS page before content authoring): the written knowledge test is offered in several foreign languages, and Russian is believed to be among them.

## Alternatives

1. Keep the English-only assumption and do nothing
2. Make the English bridge optional in explanations and drop the REQ-004 criterion
3. Keep the English bridge mandatory on real-world grounds (signs, road situations, officials speak English) and inform users about the language option

## Decision

The spec no longer claims the test is English-only. The 'Show in English' option (DEC-005) and the REQ-004 criterion that Russian explanations present the English exam term remain unchanged, justified by the fact that road signs and real-world driving in Illinois are in English and that the user may still choose to take the test in English. The app includes a short informational note that the written test can be taken in several languages (details and exact list to be verified on the official SOS page and kept up to date). The verification result is recorded as an external fact before content authoring starts.

## Reason

Bridging to English terminology is useful to the primary audience independent of the test language, so the product stays the same; only the rationale and user messaging change. Verifying first avoids giving wrong advice.

## Consequences

DEC-005 context wording is corrected. A verification task against the official SOS source is added to content prep. One informational copy element (in both languages) is added; no UI or data-model changes.

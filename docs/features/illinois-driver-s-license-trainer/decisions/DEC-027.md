## Context

DEC-023 left the generator to the owner; the owner now chooses the OpenAI image API.

## Alternatives

1. Google Imagen/Gemini
2. Adobe Firefly
3. Manual generation by the owner

## Decision

Scene, character and decorative images are generated with the OpenAI image API using an API key the owner supplies locally (OPENAI_API_KEY, never committed). The assistant provides a prompt manifest with bilingual alt text and a script that generates optimised WebP images and attaches them to content items. Images never depict signs or signals as the subject (DEC-010); sign images stay official FHWA assets. Amends DEC-023.

## Reason

Owner's tool choice; matches the pipeline in plan issue I-4.

## Consequences

The owner must set OPENAI_API_KEY and run the script (it incurs API cost); until then REQ-005 illustration criteria stay open.

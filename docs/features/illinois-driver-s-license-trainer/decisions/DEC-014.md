## Context

The FHWA SHS PDFs are engineering sheets with dimension lines and size tables around each sign, so they cannot be shown as-is without clutter.

## Alternatives

1. Use the drawings as-is (crop only)
2. Another official vector source

## Decision

A script extracts each sign from the official FHWA SHS PDF and removes dimension lines and tables, keeping the official shape, colour, symbol and text. Each asset records its publication, URL, sheet/page, designation and retrieval date in signs/*.json. Every extracted sign is checked visually against the source sheet before it is used.

## Reason

Keeps DEC-010 (official source only) while giving clean learning imagery.

## Consequences

Extraction tooling lives in scripts/; the build gate rejects sign assets without recorded source or file, and content images of signs must reference a library asset by signId.

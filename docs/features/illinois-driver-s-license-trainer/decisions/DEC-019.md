## Context

DEC-012 and DEC-017 left the pass mark and the test languages unverified. The owner told the assistant to find the documentation itself. The primary source is 92 Ill. Adm. Code 1030.80.

## Alternatives

1. Keep 28/35 provisional and the neutral note (DEC-017)

## Decision

The pass mark is 80% (28 of 35) and the question count is at least 35, per 92 Ill. Adm. Code 1030.80 (SRC-002); both are now confirmed, no longer provisional. Test languages: the rule says English plus other languages the Secretary of State deems necessary, with interpreters allowed if available; no official list was found, so the app does not list languages or claim Russian is offered. The in-app note says the test is given in English, may be offered in other languages, and that an interpreter or oral exam may be available (see ilsos.gov). Amends DEC-012 and DEC-017 and keeps DEC-007 intact (the app does not claim the test is English-only).

## Reason

Primary law is an authoritative source for the pass mark; the absence of an official language list means the note must stay general.

## Consequences

EXAM settings in src/lib/config.ts are final. The language note is reworded in both languages. If the owner finds an official language list, the note can be made specific.

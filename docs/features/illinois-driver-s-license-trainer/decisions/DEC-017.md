## Context

Neither the official manual nor the workbook states the pass mark or the list of test languages (SRC-002); the owner chose not to verify them now.

## Alternatives

1. Owner sends official values

## Decision

The simulation uses 28 of 35 correct (80%) as a provisional pass mark, marked unconfirmed in src/lib/config.ts and SRC-002. The in-app language note keeps the neutral wording (written test offered in several languages; see ilsos.gov). Both are revisited when the owner verifies the official values. Amends DEC-012.

## Reason

Keeps the product usable without stating unverified facts as fact.

## Consequences

Docs and code label both values as provisional; no copy says Russian is offered.

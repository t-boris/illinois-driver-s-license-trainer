## Context

The spec leaves the framework to the implementer (static-first, no backend per DEC-004); the owner's global rules require approval for library choices.

## Alternatives

1. Next.js static export
2. Astro with islands

## Decision

The app is a static Vite + React + TypeScript single-page app deployed to Vercel. Content is stored as structured files in the repository and validated by a Node script run in the Vercel build command (DEC-008).

## Reason

Simplest fit for a no-backend, interactive quiz app on Vercel.

## Consequences

I-2 scaffolds Vite + React + TS; I-3 validation script is wired into the build command.

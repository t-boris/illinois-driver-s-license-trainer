## Context

The real Illinois written test is most likely taken in English (assumption to verify: Russian-language testing may not be available at every facility). Russian-speaking users who study only in Russian risk being confused by unfamiliar English wording on exam day.

## Alternatives

1. A: language switch only, whole UI/content in one language
2. C: permanent bilingual mode showing both languages for every question

## Decision

The UI has a global RU/EN language switch. In addition, on every question screen (topic quiz and exam simulation) the user viewing Russian can tap 'Show in English' to see the original English wording of the question and answers next to the translation. There is no permanent dual-language mode.

## Reason

Bridges to the English exam wording with minimal UI complexity; matches the primary Russian-speaking audience.

## Consequences

Question content must be stored and authored in both languages per question (already implied by REQ-001). Question screen on phones must accommodate an optional expanded English block without hiding images. Prepares users for the English wording of the real test without cluttering the default screen.

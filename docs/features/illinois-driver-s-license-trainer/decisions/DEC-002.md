## Context

The core user journey and the definition of 'ready for the exam' had to be chosen: tests only, structured lessons, or a gamified progression.

## Alternatives

1. Q-002 A — tests only, no lessons
2. Q-002 C — gamified progression with levels, points, streaks
3. Q-005 A — readiness = N consecutive passed simulations
4. Q-005 C — no formal readiness criterion, statistics only

## Decision

The main path is: illustrated lesson per topic → quiz on that topic → full exam simulation. Progress is tracked per topic. The user is considered 'ready' when every topic has reached a correct-answer threshold AND at least one exam simulation has been passed. Readiness and weak topics are shown to the user.

## Reason

Gives systematic preparation, exposes gaps by topic, and leaves room for imagery and a playful tone. Gamification elements can be layered on later without changing the model.

## Consequences

Content must be organised into a topic list covering the manual and road signs. The implementer defines the per-topic threshold and simulation format based on the real Illinois test parameters (to be verified from official sources).

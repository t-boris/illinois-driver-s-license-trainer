## Context

DEC-013 says the assistant drafts content but never writes review records, and unreviewed items never deploy. The build gate scans content/.

## Alternatives

1. Put drafts in content/ and let the build fail until reviewed

## Decision

AI-drafted lessons and questions are stored one item per JSON file under content-drafts/<topic>/, without review records, and checked with `node scripts/validate-content.mjs content-drafts --draft` (which rejects drafts that carry review records). The owner or a designee reviews an item in RU and EN, adds the review records, and moves the file to content/ via pull request, where the full gate applies. Each question has `topic`, `pool` (quiz or exam) and `category` (sign or rule); the exam simulation draws 15 sign and 20 rule questions from the exam pool (35 total, SRC-002). Sign questions reference an official sign by `image.signId`, which must exist in signs/.

## Reason

Keeps the production build green while content awaits review and keeps DEC-013 intact.

## Consequences

content/ stays empty until the owner promotes reviewed items, so production serves an empty bank until then.

  - text: "Pass mark (official, primary law): 92 Ill. Adm. Code 1030.80 (Driver's License Testing/Written Test) requires that '80% percent must be answered correctly' and sets 'a minimum of 35 questions' for Class D. 28 of 35 is exactly 80%. Source: https://www.law.cornell.edu/regulations/illinois/Ill-Admin-Code-tit-92-SS-1030.80, retrieved 2026-10-04."
    certainty: stated
    status: accepted
  - text: "Test languages (official, primary law): 1030.80 states tests 'will be in the English language and may be in any other languages deemed necessary by the Secretary of State, based upon an identifiable demand'; a supervisor 'may provide or recommend use of an interpreter ... if an interpreter is readily available', otherwise the applicant must obtain one (not for CDL tests). The 2026 manual p. 15 adds oral exams on request for applicants with a language barrier. No official list of test languages was found on ilsos.gov (page https://www.ilsos.gov/departments/drivers/drivers-license/drlicid.html read 2026-10-04); secondary sources list English, Spanish, Chinese, Korean and Polish, not Russian."
